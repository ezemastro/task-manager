# Capturas de Pantalla - Landing Page

Este directorio contiene las imágenes que se muestran en la landing page de la aplicación.

## Capturas Necesarias

A continuación se listan todas las capturas de pantalla que necesitas agregar a este directorio:

### Hero Section
- **hero-dashboard.png** - Captura principal del dashboard para la sección hero (16:9)

### Tutorial Paso a Paso
1. **login.png** - Pantalla de inicio de sesión
2. **dashboard.png** - Vista del dashboard principal con proyectos
3. **create-project.png** - Modal de creación de proyecto
4. **stages.png** - Vista de etapas de un proyecto
5. **project-detail.png** - Detalle completo de un proyecto
6. **clients.png** - Panel de gestión de clientes
7. **templates.png** - Gestión de plantillas de etapas
8. **completed-projects.png** - Vista de proyectos completados/pausados
9. **audit-logs.png** - Panel de logs de auditoría
10. **users.png** - Administración de usuarios

### Galería de Screenshots
- **dashboard-full.png** - Vista completa del dashboard de proyectos
- **project-detail-full.png** - Vista detallada de un proyecto con etapas
- **stages-view.png** - Vista de todas las etapas en progreso
- **clients-full.png** - Panel completo de gestión de clientes
- **templates-full.png** - Vista de plantillas de etapas
- **audit-full.png** - Vista completa de logs de auditoría

## Recomendaciones

- Formato recomendado: PNG
- Resolución mínima: 1920x1080 para mejores resultados
- Aspect ratio: 16:9 para mejor visualización
- Asegúrate de que las capturas muestren datos de ejemplo representativos
- Evita incluir información sensible o real en las capturas

## Cómo Agregar las Capturas

1. Toma capturas de pantalla de la aplicación en funcionamiento
2. Guárdalas en este directorio (`/workspaces/task-manager/client/public/screenshots/`)
3. Usa los nombres exactos especificados arriba
4. Las imágenes se mostrarán automáticamente en la landing page

## Placeholders

Mientras no agregues las capturas, la landing page mostrará gradientes de color como placeholders. Las imágenes desaparecerán automáticamente si hay un error al cargarlas.
